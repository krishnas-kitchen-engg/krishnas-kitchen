# Roadmap Item Template

## Purpose

Use this template to describe planned work before it becomes a feature spec or implementation milestone.

## When To Use

Use for roadmap items that need enough context to prioritize, sequence, or de-risk future work.

## Owner

Product or engineering owns the roadmap item. Engineering owns the template.

## Update Cadence

Update when priority, scope, dependencies, or status changes.

## Lifecycle

Roadmap items are living while planned and historical after completion, cancellation, or replacement.

## Required Sections

```markdown
# Roadmap Item: <Name>

## Problem

## Outcome

## Scope

## Non-Goals

## Dependencies

## Risks

## Architecture Considerations

## Validation Approach

## Status

## Related Documents
```

## Optional Sections

- Sequencing.
- Open questions.
- Candidate milestones.
- ADR candidates.
- Operational impact.

## Review Checklist

- Outcome is clear.
- Scope is not implementation detail disguised as roadmap.
- Dependencies and risks are visible.
- Architecture impact is linked, not duplicated.
- Next milestone is identifiable.
