# Krishna's Kitchen Product Horizons

Status: Living Document

Purpose

This document defines the long-term evolution of Krishna's Kitchen.

It exists so every engineering decision supports the eventual vision while ensuring implementation remains focused on the current milestone.

The horizons are sequential.

Future horizons influence architecture.

Only the active horizon influences implementation.

---

# Product Vision

Krishna's Kitchen will become the operating system for running an ISKCON temple kitchen.

The platform should make it effortless for volunteers to serve and provide complete operational visibility to kitchen managers and temple leadership.

The long-term vision includes inventory, recipes, kitchen operations, procurement, forecasting, analytics, donations, festivals, and temple intelligence.

Only the currently active horizon should be implemented.

# Rules

The complete vision must always be understood.

Architecture should support future horizons.

Implementation must remain inside the current active horizon.

Future capabilities should only influence architecture.

Future capabilities should never expand milestone scope.

The Engineering Operating System should recommend milestones only from the active horizon unless explicitly instructed otherwise.

Evidence from implementation determines when horizons advance.

No horizon promotion occurs without explicit human approval.
